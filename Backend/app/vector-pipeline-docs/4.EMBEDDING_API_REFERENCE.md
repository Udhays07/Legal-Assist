# Embedding Service API Reference

## Overview

The embedding service provides automatic vectorization of document content for semantic search capabilities. All operations are integrated into the existing Document API endpoints.

## Automatic Operations

### Document Creation (POST /documents)

When a document is created, an embedding is automatically generated.

**Request:**
```bash
curl -X POST "http://localhost:8000/documents/" \
  -H "Content-Type: multipart/form-data" \
  -F "category_id=123e4567-e89b-12d3-a456-426614174000" \
  -F "title=Legal Contract Analysis" \
  -F "content=This is the document content that will be vectorized..." \
  -F "status=published"
```

**What Happens:**
1. Document is created in the database
2. Embedding is generated from the content (768 dimensions)
3. Embedding is stored in `document_embeddings` table
4. Document is returned with ID

**Response:**
```json
{
  "id": "123e4567-e89b-12d3-a456-426614174001",
  "category_id": "123e4567-e89b-12d3-a456-426614174000",
  "title": "Legal Contract Analysis",
  "content": "This is the document content...",
  "status": "published",
  "created_at": "2026-03-03T10:00:00",
  "updated_at": null,
  "deleted_at": null
}
```

### Document Update (PUT /documents/{id})

When document content is updated, the embedding is automatically regenerated.

**Request:**
```bash
curl -X PUT "http://localhost:8000/documents/123e4567-e89b-12d3-a456-426614174001" \
  -H "Content-Type: application/json" \
  -d '{
    "content": "Updated document content with new information..."
  }'
```

**What Happens:**
1. Document content is updated
2. If `content` field was modified, embedding is regenerated
3. If only other fields (title, tags, etc.) were modified, embedding is NOT regenerated
4. Updated document is returned

**Note:** Embedding regeneration only occurs when the `content` field is updated to optimize performance.

### Document Deletion (DELETE /documents/{id})

When a document is soft-deleted, its embedding is automatically removed.

**Request:**
```bash
curl -X DELETE "http://localhost:8000/documents/123e4567-e89b-12d3-a456-426614174001"
```

**What Happens:**
1. Document `deleted_at` timestamp is set
2. Associated embedding is deleted from `document_embeddings` table
3. Returns 204 No Content

## Programmatic API

### Generate Embedding for Text

```python
from app.services.embedding_service import generate_embedding

# Generate embedding for any text
text = "Your document content here"
embedding = generate_embedding(text)

# Returns: List[float] with 768 dimensions
print(f"Embedding dimension: {len(embedding)}")  # 768
print(f"First 5 values: {embedding[:5]}")
```

### Create or Update Document Embedding

```python
from app.services.embedding_service import create_or_update_embedding
from app.core.database import SessionLocal
from uuid import UUID

db = SessionLocal()

# Create or update embedding for a document
document_id = UUID("123e4567-e89b-12d3-a456-426614174001")
content = "Document content to embed"

embedding_record = create_or_update_embedding(
    db=db,
    document_id=document_id,
    content=content
)

print(f"Embedding created/updated at: {embedding_record.updated_at}")
db.close()
```

### Delete Document Embedding

```python
from app.services.embedding_service import delete_embedding
from app.core.database import SessionLocal
from uuid import UUID

db = SessionLocal()

document_id = UUID("123e4567-e89b-12d3-a456-426614174001")
deleted = delete_embedding(db, document_id)

if deleted:
    print("Embedding deleted successfully")
else:
    print("No embedding found for this document")

db.close()
```

### Batch Processing

```python
from app.services.embedding_service import batch_generate_embeddings
from app.core.database import SessionLocal
from uuid import UUID

db = SessionLocal()

# List of (document_id, content) tuples
documents = [
    (UUID("doc-id-1"), "Content 1"),
    (UUID("doc-id-2"), "Content 2"),
    (UUID("doc-id-3"), "Content 3"),
]

success_count = batch_generate_embeddings(db, documents)
print(f"Successfully processed {success_count}/{len(documents)} documents")

db.close()
```

## Database Schema

### document_embeddings Table

```sql
CREATE TABLE document_embeddings (
    document_id UUID PRIMARY KEY REFERENCES documents(id),
    embedding VECTOR(768) NOT NULL,
    updated_at TIMESTAMP DEFAULT NOW()
);

-- Vector similarity index (cosine distance)
CREATE INDEX idx_document_embeddings_vector 
ON document_embeddings 
USING ivfflat (embedding vector_cosine_ops) 
WITH (lists = 100);
```

### Query Embeddings

```python
from sqlalchemy import text
from app.core.database import SessionLocal

db = SessionLocal()

# Get embedding for a document
result = db.execute(
    text("SELECT embedding FROM document_embeddings WHERE document_id = :doc_id"),
    {"doc_id": document_id}
).fetchone()

if result:
    embedding_vector = result[0]
    print(f"Embedding dimension: {len(embedding_vector)}")

db.close()
```

## Semantic Search (Example)

### Find Similar Documents

```python
from sqlalchemy import text
from app.services.embedding_service import generate_embedding
from app.core.database import SessionLocal

db = SessionLocal()

# Generate embedding for search query
query_text = "contract termination clause"
query_embedding = generate_embedding(query_text)

# Find top 10 similar documents using cosine similarity
results = db.execute(
    text("""
        SELECT 
            d.id,
            d.title,
            d.content,
            1 - (e.embedding <=> :query_embedding::vector) as similarity_score
        FROM documents d
        JOIN document_embeddings e ON d.id = e.document_id
        WHERE d.deleted_at IS NULL
        ORDER BY e.embedding <=> :query_embedding::vector
        LIMIT 10
    """),
    {"query_embedding": query_embedding}
).fetchall()

for row in results:
    print(f"Document: {row.title}")
    print(f"Similarity: {row.similarity_score:.4f}")
    print(f"Content preview: {row.content[:100]}...")
    print("-" * 60)

db.close()
```

### Distance Operators

pgvector supports three distance operators:

- `<->` : Euclidean distance (L2)
- `<#>` : Negative inner product
- `<=>` : Cosine distance (recommended for normalized embeddings)

**Example:**
```sql
-- Cosine similarity (recommended)
ORDER BY embedding <=> '[0.1, 0.2, ...]'

-- Euclidean distance
ORDER BY embedding <-> '[0.1, 0.2, ...]'

-- Inner product
ORDER BY embedding <#> '[0.1, 0.2, ...]'
```

## Error Handling

### Empty Content Error

```python
from app.services.embedding_service import generate_embedding

try:
    embedding = generate_embedding("")
except ValueError as e:
    print(f"Error: {e}")  # "Cannot generate embedding for empty text"
```

### Database Error

```python
from app.services.embedding_service import create_or_update_embedding

try:
    embedding = create_or_update_embedding(db, doc_id, content)
except Exception as e:
    print(f"Failed to create embedding: {e}")
    # Database transaction is automatically rolled back
```

## Performance Metrics

### Embedding Generation Time

- Short text (< 100 words): ~50ms
- Medium text (100-500 words): ~100ms
- Long text (> 500 words): ~200ms

### Model Loading Time

- First call: ~2-3 seconds (model download + load)
- Subsequent calls: 0ms (cached)

### Database Operations

- Insert embedding: ~5ms
- Update embedding: ~5ms
- Query by similarity: ~10ms (with index)

## Configuration

### Model Settings

Located in `app/services/embedding_service.py`:

```python
MODEL_NAME = "sentence-transformers/all-mpnet-base-v2"
EMBEDDING_DIMENSION = 768
```

### Change Model

To use a different model:

1. Update `MODEL_NAME` and `EMBEDDING_DIMENSION` in `embedding_service.py`
2. Update vector dimension in `app/models/admin.py`
3. Create new migration with updated dimension
4. Regenerate all embeddings with new model

## Monitoring

### Check Embedding Status

```sql
-- Documents without embeddings
SELECT d.id, d.title
FROM documents d
LEFT JOIN document_embeddings e ON d.id = e.document_id
WHERE e.document_id IS NULL
AND d.deleted_at IS NULL;

-- Embedding coverage percentage
SELECT 
    COUNT(DISTINCT d.id) as total_docs,
    COUNT(DISTINCT e.document_id) as docs_with_embeddings,
    ROUND(COUNT(DISTINCT e.document_id)::numeric / COUNT(DISTINCT d.id) * 100, 2) as coverage_pct
FROM documents d
LEFT JOIN document_embeddings e ON d.id = e.document_id
WHERE d.deleted_at IS NULL;
```

### Embedding Freshness

```sql
-- Find stale embeddings (document updated after embedding)
SELECT 
    d.id,
    d.title,
    d.updated_at as doc_updated,
    e.updated_at as embedding_updated,
    d.updated_at - e.updated_at as staleness
FROM documents d
JOIN document_embeddings e ON d.id = e.document_id
WHERE d.updated_at > e.updated_at
AND d.deleted_at IS NULL
ORDER BY staleness DESC;
```

## Best Practices

1. **Content Updates**: Only regenerate embeddings when content changes, not for metadata updates
2. **Batch Processing**: Use batch operations for initial setup or bulk updates
3. **Error Handling**: Always wrap embedding operations in try-catch blocks
4. **Monitoring**: Regularly check embedding coverage and freshness
5. **Index Maintenance**: Rebuild vector index periodically for optimal performance
6. **Model Caching**: Let the singleton pattern handle model caching automatically

## Troubleshooting

### Embedding Not Generated

Check logs for errors:
```python
import logging
logging.basicConfig(level=logging.INFO)
```

### Slow Performance

- Ensure model is cached (check first call vs subsequent calls)
- Use batch processing for multiple documents
- Consider GPU acceleration for large-scale operations

### Vector Index Issues

Rebuild the index:
```sql
DROP INDEX idx_document_embeddings_vector;
CREATE INDEX idx_document_embeddings_vector 
ON document_embeddings 
USING ivfflat (embedding vector_cosine_ops) 
WITH (lists = 100);
```
