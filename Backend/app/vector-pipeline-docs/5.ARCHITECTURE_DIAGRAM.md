## Data Flow Diagrams

### 1. Document Creation Flow

```
┌─────────┐
│ Client  │
└────┬────┘
     │
     │ POST /documents
     │ {title, content, category_id}
     ▼
┌─────────────────────┐
│ document.py         │
│ create_document()   │
└────┬────────────────┘
     │
     │ 1. Validate input
     │ 2. Create Document object
     │ 3. Save to database
     ▼
┌─────────────────────┐
│ Database            │
│ INSERT INTO         │
│ documents           │
└────┬────────────────┘
     │
     │ 4. Document saved
     │    doc.id = UUID
     ▼
┌─────────────────────┐
│ embedding_service.py│
│ create_or_update_   │
│ embedding()         │
└────┬────────────────┘
     │
     │ 5. Load model (if not cached)
     │ 6. Generate embedding
     ▼
┌─────────────────────┐
│ ML Model            │
│ all-mpnet-base-v2   │
│ encode(content)     │
└────┬────────────────┘
     │
     │ 7. Returns 768-dim vector
     ▼
┌─────────────────────┐
│ Database            │
│ INSERT INTO         │
│ document_embeddings │
└────┬────────────────┘
     │
     │ 8. Embedding saved
     ▼
┌─────────┐
│ Client  │
│ Response│
│ 201     │
└─────────┘
```

### 2. Document Update Flow

```
┌─────────┐
│ Client  │
└────┬────┘
     │
     │ PUT /documents/{id}
     │ {content: "new content"}
     ▼
┌─────────────────────┐
│ document.py         │
│ update_document()   │
└────┬────────────────┘
     │
     │ 1. Find document
     │ 2. Update fields
     │ 3. Check if content changed
     ▼
┌─────────────────────┐
│ Database            │
│ UPDATE documents    │
│ SET content = ...   │
└────┬────────────────┘
     │
     │ 4. If content changed
     ▼
┌─────────────────────┐
│ embedding_service.py│
│ create_or_update_   │
│ embedding()         │
└────┬────────────────┘
     │
     │ 5. Generate new embedding
     ▼
┌─────────────────────┐
│ Database            │
│ UPDATE              │
│ document_embeddings │
│ SET embedding = ... │
└────┬────────────────┘
     │
     │ 6. Embedding updated
     ▼
┌─────────┐
│ Client  │
│ Response│
│ 200     │
└─────────┘
```

### 3. Document Deletion Flow

```
┌─────────┐
│ Client  │
└────┬────┘
     │
     │ DELETE /documents/{id}
     ▼
┌─────────────────────┐
│ document.py         │
│ delete_document()   │
└────┬────────────────┘
     │
     │ 1. Find document
     │ 2. Soft delete (set deleted_at)
     ▼
┌─────────────────────┐
│ Database            │
│ UPDATE documents    │
│ SET deleted_at = NOW│
└────┬────────────────┘
     │
     │ 3. Document soft-deleted
     ▼
┌─────────────────────┐
│ embedding_service.py│
│ delete_embedding()  │
└────┬────────────────┘
     │
     │ 4. Remove embedding
     ▼
┌─────────────────────┐
│ Database            │
│ DELETE FROM         │
│ document_embeddings │
└────┬────────────────┘
     │
     │ 5. Embedding deleted
     ▼
┌─────────┐
│ Client  │
│ Response│
│ 204     │
└─────────┘
```

### 4. Semantic Search Flow (Future)

```
┌─────────┐
│ Client  │
└────┬────┘
     │
     │ POST /search/semantic
     │ {query: "contract terms"}
     ▼
┌─────────────────────┐
│ search.py           │
│ semantic_search()   │
└────┬────────────────┘
     │
     │ 1. Generate query embedding
     ▼
┌─────────────────────┐
│ embedding_service.py│
│ generate_embedding()│
└────┬────────────────┘
     │
     │ 2. Query embedding: [0.1, 0.2, ...]
     ▼
┌─────────────────────┐
│ Database            │
│ SELECT ... FROM     │
│ document_embeddings │
│ ORDER BY embedding  │
│ <=> query_vector    │
└────┬────────────────┘
     │
     │ 3. Top 10 similar documents
     ▼
┌─────────┐
│ Client  │
│ Response│
│ 200     │
│ [docs]  │
└─────────┘
```
