# 📋 Vectorization Pipeline - Deployment Checklist

Use this checklist to ensure the vectorization pipeline is properly deployed and operational.

## Pre-Deployment Checklist

### 1. System Requirements
- [ ] PostgreSQL 12+ installed
- [ ] Python 3.12.0 installed
- [ ] At least 1GB free disk space (for model)
- [ ] At least 1GB free RAM (for model in memory)

### 2. PostgreSQL pgvector Extension
- [ ] pgvector extension installed on system
- [ ] pgvector extension enabled in database
  ```sql
  -- Run this to verify
  SELECT * FROM pg_available_extensions WHERE name = 'vector';
  SELECT * FROM pg_extension WHERE extname = 'vector';
  ```

### 3. Python Dependencies
- [ ] All requirements installed
  ```bash
  # Verify Python version first
  python --version  # Should show Python 3.12.0
  
  pip install -r requirements.txt
  ```
- [ ] Verify installations:
  ```bash
  python -c "import sentence_transformers; print('✓ sentence-transformers')"
  python -c "import pgvector; print('✓ pgvector')"
  python -c "import torch; print('✓ torch')"
  ```

## Deployment Steps

### Step 1: Database Migration
- [ ] Run migration
  ```bash
  cd Backend
  alembic upgrade head
  ```
- [ ] Verify migration applied
  ```bash
  alembic current
  # Should show: add_embeddings_001
  ```
- [ ] Verify table created
  ```sql
  SELECT table_name FROM information_schema.tables 
  WHERE table_name = 'document_embeddings';
  ```

### Step 2: Test Installation
- [ ] Run test suite
  ```bash
  python test_embedding_pipeline.py
  ```
- [ ] All 4 tests pass:
  - [ ] Model Loading
  - [ ] Embedding Generation
  - [ ] Database Operations
  - [ ] Error Handling

### Step 3: Start Application
- [ ] Start server
  ```bash
  uvicorn app.main:app --reload
  ```
- [ ] Server starts without errors
- [ ] Check logs for any warnings

### Step 4: Verify Health Endpoints
- [ ] Health check responds
  ```bash
  curl http://localhost:8000/embeddings/health
  ```
  Expected: `"status": "healthy"`

- [ ] Stats endpoint responds
  ```bash
  curl http://localhost:8000/embeddings/stats
  ```
  Expected: JSON with statistics

### Step 5: Test Document Creation
- [ ] Create a test document
  ```bash
  curl -X POST "http://localhost:8000/documents/" \
    -F "category_id=YOUR_CATEGORY_ID" \
    -F "title=Test Document" \
    -F "content=This is a test document for embedding verification."
  ```
- [ ] Document created successfully
- [ ] Check logs for embedding generation message
- [ ] Verify embedding in database
  ```sql
  SELECT COUNT(*) FROM document_embeddings;
  -- Should be > 0
  ```

### Step 6: Test Document Update
- [ ] Update document content
  ```bash
  curl -X PUT "http://localhost:8000/documents/DOC_ID" \
    -H "Content-Type: application/json" \
    -d '{"content": "Updated content for testing."}'
  ```
- [ ] Document updated successfully
- [ ] Check logs for embedding update message
- [ ] Verify embedding updated_at timestamp changed

### Step 7: Test Document Deletion
- [ ] Delete test document
  ```bash
  curl -X DELETE "http://localhost:8000/documents/DOC_ID"
  ```
- [ ] Document deleted successfully
- [ ] Verify embedding removed from database
  ```sql
  SELECT COUNT(*) FROM document_embeddings WHERE document_id = 'DOC_ID';
  -- Should be 0
  ```

## Post-Deployment Verification

### 1. Model Loading
- [ ] Model loads on first request (~2-3 seconds)
- [ ] Subsequent requests are fast (<100ms)
- [ ] No model download errors in logs
- [ ] Model cached in memory

### 2. Embedding Generation
- [ ] Embeddings generated for new documents
- [ ] Embedding dimension is 768
- [ ] Generation time is reasonable (<200ms)
- [ ] No generation errors in logs

### 3. Database Operations
- [ ] Embeddings stored correctly
- [ ] Vector index exists and works
  ```sql
  SELECT indexname FROM pg_indexes 
  WHERE tablename = 'document_embeddings';
  -- Should show: idx_document_embeddings_vector
  ```
- [ ] Queries execute quickly (<10ms)

### 4. Error Handling
- [ ] Empty content handled gracefully
- [ ] Database errors don't crash application
- [ ] Embedding errors don't prevent document operations
- [ ] Errors logged appropriately

### 5. Monitoring
- [ ] Health endpoint accessible
- [ ] Stats endpoint shows correct data
- [ ] Missing embeddings endpoint works
- [ ] Stale embeddings endpoint works

## Troubleshooting Reference

### Common Issues

| Issue | Check | Solution |
|-------|-------|----------|
| Model won't load | Disk space, internet | Clear cache, re-download |
| Slow embedding | CPU usage, model cached | Wait for cache, check resources |
| Missing embeddings | Logs, batch script | Run batch processing |
| Database errors | Connection, pgvector | Check extension, restart DB |
| High memory | Model size, leaks | Normal for model, monitor |
